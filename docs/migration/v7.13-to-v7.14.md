# FTPGrab v7.13 to v7.14

## SFTP host key verification

Starting with v7.14.0, FTPGrab verifies SFTP server host keys. Earlier versions
accepted any server host key. Existing SFTP connections now require a trusted
key in an OpenSSH known_hosts file.

Before upgrading, populate the file with server keys verified through a
trusted channel, such as the server administrator. If using `ssh-keyscan` to
collect keys, verify their fingerprints independently before trusting them.
For a legitimate key rotation, verify the replacement key before updating the
file.

By default, FTPGrab reads `.ssh/known_hosts` in the running user's home
directory. To use a different file, set
[`server.sftp.knownHostsFile`](../config/server/sftp.md#knownhostsfile) or
`FTPGRAB_SERVER_SFTP_KNOWNHOSTSFILE`:

```yaml
server:
  sftp:
    knownHostsFile: /etc/ftpgrab/known_hosts
```

For Docker deployments, mount a populated known_hosts file read-only and set
the configuration to its container path. The image does not include trusted
server keys.

Missing or malformed files, unknown hosts, and mismatched keys cause the
connection to fail. FTPGrab does not create the file, automatically trust new
keys, or offer an option to skip verification.
